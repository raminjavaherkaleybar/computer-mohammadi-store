# فروشگاه کامپیوتر محمدی

فروشگاه مستقل لوازم جانبی موبایل و کامپیوتر.

## فایل‌ها
- `index.html`: فروشگاه مشتریان؛ نمایش دسته‌ها و محصولات فعال و ثبت درخواست سفارش.
- `product.html`: صفحه جزئیات محصول، افزودن به سبد خرید و اشتراک‌گذاری لینک محصول.
- `track-order.html`: پیگیری سفارش با شماره سفارش و موبایل؛ نمایش وضعیت پرداخت، آماده‌سازی و کد رهگیری.
- `admin.html`: پنل مدیر برای مدیریت کالاها، موجودی، سفارش‌ها، تعرفه ارسال و گزارش فروش.

## انتشار مستقل
این مخزن جدا از سایت رام آنلاین است و با GitHub Pages از شاخه `main` منتشر می‌شود.
نشانی پس از فعال شدن GitHub Pages:
`https://raminjavaherkaleybar.github.io/computer-mohammadi-store/`

در تنظیمات مخزن، بخش **Settings → Pages → Build and deployment**، گزینه **GitHub Actions** را انتخاب کنید. فایل گردش‌کار انتشار در `.github/workflows/deploy-pages.yml` قرار دارد.

## زیرساخت فروشگاه
- پروژه Supabase مستقل: `fgfeiilkzoajguabzuex`
- URL: `https://fgfeiilkzoajguabzuex.supabase.co`
- جداول اختصاصی: categories, products, customers, orders, order_items, inventory_movements, store_settings
- کلید عمومی Supabase در سمت مرورگر استفاده می‌شود؛ کلید service-role نباید در فایل‌های عمومی قرار گیرد.
- پنل مدیر از حساب Supabase Auth و ایمیل مجاز مدیر استفاده می‌کند.
- محصولات و قیمت‌ها باید فقط پس از تهیه کالا و تأیید موجودی واقعی در پنل ثبت شوند؛ محصول آزمایشی یا قیمت ساختگی وارد نکنید.

## سفارش و ارسال
- درخواست سفارش در وضعیت «در انتظار تأیید» ثبت می‌شود.
- تعرفه پیش‌فرض پست از تنظیمات پنل خوانده می‌شود. تعرفه تیپاکس نیز قابل تنظیم است؛ مقدار صفر به معنی استعلام دستی هزینه بر اساس مقصد و وزن است.
- هزینه ارسال و روش پرداخت فعلاً با مشتری هماهنگ می‌شود و پرداخت آنلاین فعال نیست.
- مدیر می‌تواند وضعیت سفارش، تأیید پرداخت، روش ارسال، هزینه و کد رهگیری را در پنل مدیریت کند.
- گزارش درآمد با تابع تجمیعی پایگاه داده، تمام سفارش‌های پرداخت‌شده و لغونشده را محاسبه می‌کند؛ فهرست مدیریتی سفارش‌ها برای سرعت، ۵۰۰ سفارش آخر را نشان می‌دهد.
- اعلان‌های روبیکا از طریق توابع امن سمت سرور پروژه مستقل انجام می‌شوند؛ توکن ربات و سایر Secretها را در GitHub یا HTML قرار ندهید.

## موارد باقی‌مانده
- آزمون کامل خرید، ثبت سفارش، دریافت تصویر رسید روبیکا، تأیید پرداخت و پیگیری سفارش با یک سفارش واقعی و محصول واقعی انجام شود.
- درگاه پرداخت و اتصال خودکار هزینه حمل به پست/تیپاکس هنوز راه‌اندازی نشده‌اند.
- قابلیت جلوگیری از گذرواژه‌های افشاشده در تنظیمات Supabase Auth از داشبورد پروژه فعال شود؛ دسترسی تنظیمات مدیریتی Auth از اتصال فعلی ابزار فراهم نیست.

## جداسازی از رام آنلاین
این مخزن و پروژه Supabase آن مستقل هستند. به مخزن `raminjavaherkaleybar/ram-online`، دامنه `raminjavaher.ir` و وب‌هوک فعلی ربات رام آنلاین تغییری داده نمی‌شود.

## تجربه نصب و امنیت تکمیلی
- فروشگاه به‌صورت PWA قابل نصب روی موبایل و رایانه است؛ فایل‌های اصلی رابط کاربری برای بازشدن پوسته سایت در حالت آفلاین ذخیره می‌شوند. ثبت سفارش، دریافت قیمت/موجودی، پیگیری زنده و ارتباط با روبیکا همچنان به اینترنت نیاز دارند.
- فایل‌های `manifest.webmanifest` و `sw.js` تنظیمات نصب و کش محدود پوسته را فراهم می‌کنند؛ پنل مدیریت و درخواست‌های API در کش آفلاین ذخیره نمی‌شوند.
- ثبت سفارش از Edge Function سمت سرور انجام می‌شود؛ اجرای مستقیم تابع `place_store_order` از نقش‌های عمومی و کاربران واردشده لغو شده و فقط `service_role` اجازه اجرا دارد.
- دسترسی مستقیم نقش‌های `anon` و `authenticated` به جدول‌های رسید پرداخت و نشست رسید روبیکا لغو شده است؛ توابع سمت سرور با `service_role` به آن‌ها دسترسی دارند.
- تابع پیگیری سفارش برای مشتریان مهمان فعال باقی مانده است؛ دسترسی نقش authenticated به آن لغو شده. اطلاعات پیگیری با شماره سفارش و شماره موبایل تطبیق داده می‌شود.
- نقشه سایت در `sitemap.xml` قرار دارد و از `robots.txt` معرفی شده است؛ داده ساختاریافته فروشگاه نیز به صفحه اصلی افزوده شده است.

## وضعیت اجرای برنامه ۸ مرحله‌ای رام‌تک — ۲۸ نوامبر ۲۰۲۶

بررسی مخزن و پروژه Supabase مستقل رام‌تک انجام شد. امکانات زیر در کد فعلی وجود دارند و برای جلوگیری از دوباره‌کاری، از نو ساخته نشده‌اند:

1. **جست‌وجوی هوشمند:** نرمال‌سازی حروف فارسی/عربی، جست‌وجوی بخشی و امتیازدهی به تطبیق‌های نزدیک و خطاهای تایپی؛ جست‌وجو در نام، دسته‌بندی، توضیحات و کد کالا.
2. **صفحه اختصاصی محصول:** تصویر اصلی و گالری، مشخصات فنی، ضمانت، موجودی، قیمت، داده ساختاریافته محصول و محصولات مرتبط.
3. **علاقه‌مندی‌ها:** افزودن/حذف از فهرست علاقه‌مندی‌ها و فیلتر نمایش علاقه‌مندی‌ها؛ ذخیره فعلی در مرورگر همان دستگاه با localStorage انجام می‌شود.
4. **پیگیری سفارش:** تطبیق شماره سفارش و موبایل، وضعیت پرداخت و آماده‌سازی، روش ارسال و کد رهگیری؛ محدودیت تعداد درخواست نیز فعال است.
5. **نظرات و امتیازها:** ثبت نظر فقط برای سفارش پرداخت‌شده و تحویل‌شده، یک نظر برای هر محصول در هر سفارش، و نمایش پس از تأیید مدیر.
6. **پیشنهاد خرید مکمل:** محصولات مرتبط و مکمل در صفحه محصول؛ مدیریت پیشنهادهای مکمل از پنل مدیر.
7. **باشگاه مشتریان:** امتیازدهی خودکار پس از پرداخت، سطح‌بندی مشتری و ایجاد کد تخفیف؛ نمایش امتیاز و کوپن با شماره سفارش و موبایل.
8. **پنل مدیریت پیشرفته:** داشبورد فروش و مالی، محصولات و دسته‌ها، سفارش‌ها و رسیدها، موجودی و گردش کالا، خرید و تأمین‌کننده، هزینه‌ها، مرجوعی، پیشنهاد مکمل، نظرات، درخواست موجودی و باشگاه مشتریان.

### تکمیل امنیت و کارایی پایگاه داده

- برای RPCهای عمومی پیگیری سفارش، ثبت نظر و مشاهده امتیاز مشتری، search_path به مقدار خالی محدود شد تا وابستگی به اشیای ناخواسته در مسیر جست‌وجوی PostgreSQL حذف شود.
- برای RPCهای مشاهده امتیاز مشتری و ثبت نظر، محدودیت تلاش بر اساس IP با استفاده از جدول موجود order_tracking_attempts افزوده شد؛ منطق پیگیری سفارش نیز حفظ شد.
- سیاست‌های مشاهده و به‌روزرسانی درخواست موجودی کالا با الگوی (select auth.jwt()) بهینه شدند تا ارزیابی تکراری احراز هویت برای هر ردیف کاهش یابد.
- دسترسی مهمان به RPCهای لازم برای پیگیری سفارش، ثبت نظر و مشاهده امتیاز حفظ شد؛ این دسترسی‌ها برای جریان خرید مهمان لازم هستند و نباید با بستن عمومی RPCها از کار بیفتند.
- جدول‌های داخلی رسید، نشست روبیکا، صف اعلان‌ها و تنظیمات پرداخت همچنان با RLS فعال و بدون سیاست عمومی باقی مانده‌اند؛ این وضعیت عمدی است.
- در این مرحله هیچ محصولی اضافه/حذف نشد و قیمت محصولات موجود تغییر نکرد.

### مواردی که نیازمند اقدام بیرون از کد هستند

- قابلیت جلوگیری از گذرواژه‌های افشاشده باید از بخش Authentication تنظیمات پروژه Supabase فعال شود.
- آزمون نهایی سفارش واقعی، ارسال رسید در روبیکا و تحویل فاکتور PDF باید با یک سفارش واقعی انجام شود.
- درگاه پرداخت آنلاین و استعلام خودکار تعرفه پست/تیپاکس هنوز فعال نیستند.
- علاقه‌مندی‌ها فعلاً بین دستگاه‌های مختلف همگام نمی‌شوند، چون ورود حساب مشتری در فروشگاه پیاده‌سازی نشده است.

**محدوده تغییرات:** فقط مخزن computer-mohammadi-store و پروژه Supabase با شناسه fgfeiilkzoajguabzuex. به پروژه و مخزن رامین جواهر و رام آنلاین تغییری داده نشد.

## قابلیت‌های مشتری و فروش (افزوده‌شده)

- زمان تحویل دقیق تا زمان هماهنگی مقصد و تحویل مرسوله به شرکت حمل تضمین نمی‌شود؛ تعرفه پایه پست از تنظیمات جاری خوانده می‌شود و تیپاکس نیازمند استعلام است.
